## 怎麼分工

**THEORY.md 放跟調無關的東西**：三度／七度／九度／十一度的定義，疊三度怎麼算出和弦，
級數標記與 9／11 音程標記的判準，以及各調式的通用性質——全半排列、與同主音大調的差異、
各級和弦性質（以羅馬級數表示，換調不會變）。

**七份調檔案只放結果**：該調的實際音名、實際和弦、相對大調與調號、特徵音落在哪三個和弦。
每份 23 組音階、161 個級數，每一級都列出三和弦、七和弦、九和弦、十一和弦與完整組成音。

所以要查「Dorian 的 IV 為什麼是大三和弦」看 THEORY.md，
要查「E Dorian 的 IV 是哪個和弦」看 E.md。

## 核心觀念

和弦是**算出來的**，不是規定的。音階的全半排列一變，疊三度算出來的結果就跟著變。
不需要背，可以推。

而且改動不會只影響一個和弦：一個音會出現在三個和弦裡（該級、往下兩級、往下四級），
所以動一個音，必定有三個級數跟著變。Dorian 和 Aeolian 只差一個音，
但 ii、IV、vi 三個和弦全部不同——這是必然的，不是巧合。
